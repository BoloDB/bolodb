# Cloud data warehouse drivers — Snowflake, Databricks and BigQuery.
#
# Kept out of requirements.txt because they are enormous: between them they pull
# pandas, numpy, pyarrow, boto3, grpcio and protobuf, which together are several
# hundred megabytes and a large amount of code that most deployments never
# execute. Everything BoloDB itself needs to *support* these dialects — the
# traits table, URL validation, the read-only guard, the prompt hints — lives in
# backend/app/dialects.py and ships in the base install; only the drivers are
# optional, and DatabaseManager.connect reports a missing one by name rather
# than failing with an import traceback.
#
# Install alongside the base requirements:
#     pip install -r backend/requirements.txt -r backend/requirements-warehouses.txt
#
# For the Docker images, build with --build-arg INSTALL_WAREHOUSE_DRIVERS=true.
#
# Oracle is deliberately *not* here: python-oracledb is a small pure-Python
# driver with no heavy dependencies, so it stays in the base install alongside
# the other operational databases.
